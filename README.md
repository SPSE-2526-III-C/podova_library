# Library

## Inteligentná webová aplikácia pre správu kníh, čitateľský denník a personalizované odporúčania 

### Cieľ / produkt: 
• webová aplikácia na správu kníh a čitateľského denníka 
• používateľ bude mať možnosť evidovať knihy, hodnotiť ich a zapisovať 
poznámky 
• aplikácia bude obsahovať odporúčací systém a štatistiky čítania 
### Hlavné funkcionality – jadro projektu: 
• registrácia a prihlásenie používateľa 
• pridane knihy (manuálne alebo cez API) 
• evidencia kníh (prečítané / čítam / plánujem čítať) 
• hodnotenie kníh (1–5) 
• poznamky 
• vyhľadávanie a filtrovanie kníh 
### Doplňujúce funkcionality: 
• odporúčanie kníh na základe hodnotení a preferencií používateľa 
• integrácia externého API (napr. Google Books) 
• automatické načítanie údajov o knihe (obálka, popis, autor) 
• kontakt na email
• responzívny dizajn (mobil, tablet) 
### Technológie: 
• frontend: HTML, CSS, JavaScript (React / Vue) 
• backend: Python (Flask / Django) alebo Node.js 
• databáza: PostgreSQL / SQLite 
• externé API (Google Books) 
• základný odporúčací algoritmus
